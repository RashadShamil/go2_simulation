# Module 03 — Robot data, odometry, IMU and LiDAR

These are *learning tasks to do after the basic movement lab*. Topic availability depends on enabled sensors and launch configuration.

## Verify topics live

```bash
ros2 topic list -t
ros2 topic echo /clock --once
ros2 topic echo /odom --once
ros2 topic echo /odom/ground_truth --once
ros2 topic echo /imu/data --once
ros2 topic hz /imu/data
ros2 topic echo /joint_states --once
ros2 run tf2_tools view_frames
```

Use `ros2 topic list -t` first. If a topic is absent, don't assume that the simulator is broken: some sensors are intentionally disabled.

The upstream launch bridges `/imu/data`, `/odom/ground_truth`, `/clock`, and selected sensor topics. `/odom` is generated by a filter node in the launch. These represent **different estimation or simulator reference paths**, not three identical measurements.

## A useful research question

**How far does filtered odometry drift relative to simulator ground-truth pose?**

Do not call ground-truth odometry 'actual real-world truth': it is only the simulator's reference state under its own physics model. Keep time synchronization, frames and measurement definitions in your notes.

## Record your first bag

In a new terminal, with the robot already running:

```bash
source /opt/ros/jazzy/setup.bash
source ~/go2_ws/install/setup.bash
mkdir -p ~/go2_simulation_lab/experiments/bags
cd ~/go2_simulation_lab/experiments/bags
ros2 bag record -o go2_basics_01 /clock /cmd_vel /odom /odom/ground_truth /imu/data
```

Press Ctrl+C to finish. If some topics are not present, remove them from the record command after checking `ros2 topic list -t`.

Inspect it later:

```bash
ros2 bag info ~/go2_simulation_lab/experiments/bags/go2_basics_01
```

## Enable LiDAR later

The `start_go2.sh` command disables the two 3D LiDAR models for performance. When ready, enable one at a time by launching with the desired sensor flag set to `false` instead. Check what ROS topic the model actually exposes with `ros2 topic list -t` before hardcoding a PointCloud2 subscriber.

**Research caution:** A standard simulated LiDAR beam does not automatically reproduce glass refraction, mirror reflection, multipath, or ghost points seen with a real sensor. Treat synthetic data as a controlled test, and use real Go2 bags to verify sensor-artifact hypotheses.
