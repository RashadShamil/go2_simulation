# Lesson 08 — Sim-to-real validation

A simulation is not a validated digital twin merely because it resembles the physical office.

Measure room geometry, motion response, and sensor ranges in both simulated and real trials. Note coordinate frames, time synchronization, calibration and environmental changes.

For reflective or transparent surfaces, standard Gazebo ray-casting can be unrealistically ideal. Validate against physical measurements; if necessary implement experimentally justified noise or ghost-return models.

**Deliverable:** versioned measurements, parameters, uncertainty estimates, comparison plots, and failure analysis.
