# Lesson 00 — Measure a real office

**Goal:** replace a visual approximation with measurable geometry.

A useful robot simulation needs correct obstacle placement, collision geometry, floor level, and robot start pose. It does not need photorealistic graphics at first.

Make a floor plan in metres. Choose the origin at the room centre, +X right, +Y north, +Z up. Record width, depth, door positions, desk footprints, and the Go2 start pose. For each measurement, include uncertainty (for example 1.20 ± 0.02 m).

**Experiment:** measure three landmarks and make a table of predicted versus measured distances. Do not upload a real office's private layout, photos, or security details to this public repository without permission.
